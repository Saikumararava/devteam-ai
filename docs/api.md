# DevTeam AI — REST & SSE API Reference

Base URL: `http://127.0.0.1:8000/api`

## Health & Model Probes

### `GET /health`
Returns backend service health and environment.

**Response:**
```json
{
  "status": "ok",
  "service": "DevTeam AI",
  "environment": "development"
}
```

### `GET /model/status`
Checks connectivity to local Ollama instance and availability of `qwen2.5-coder:1.5b`.

**Response:**
```json
{
  "connected": true,
  "base_url": "http://127.0.0.1:11434",
  "configured_model": "qwen2.5-coder:1.5b",
  "model_available": true,
  "available_models": ["qwen2.5-coder:1.5b"],
  "error": null,
  "inference_notes": "CPU-only inference is enabled..."
}
```

## Projects & Workflow

### `GET /projects`
List all saved projects in descending chronological order.

### `POST /projects`
Create a new project from a requirements brief.

**Payload:**
```json
{
  "name": "Warehouse Inventory API",
  "description": "Inventory stock tracking service",
  "tech_preferences": "Python, FastAPI",
  "functional_requirements": "CRUD endpoints for items with stock levels",
  "expected_output": "FastAPI service with Pytest suite and README"
}
```

### `GET /projects/stats`
Summary dashboard counts: total projects, completed projects, active agents.

### `GET /projects/activity`
Last 10 workflow audit events across all projects.

### `POST /projects/{id}/start`
Initiates the 5-agent LangGraph workflow in a background thread. Returns immediately.

### `GET /projects/{id}/stream`
**Server-Sent Events (SSE)** endpoint. Streams real-time agent updates and audit events to the client.

Event types:
- `event`: Audit event log entry (`planner.start`, `developer.complete`, etc.)
- `agents`: Real-time status, progress %, and task for all 5 agents.
- `done`: Emitted when the entire pipeline terminates.

## Artifacts & Inspecting Code

### `GET /projects/{id}/files`
List all source files generated by the Developer agent with file sizes and detected languages.

### `GET /projects/{id}/files/content?path={path}`
Fetch text content of an individual generated file.

### `GET /projects/{id}/download`
Download the entire generated project codebase as a `.zip` archive.

---

## Quality, Review & Testing

### `GET /projects/{id}/review`
Returns quality score, approval status, and structured findings with severity levels and suggested code fixes.

### `GET /projects/{id}/tests`
Returns passed, failed, and skipped test counts, assertion details, test strategy plan, and raw pytest runner stdout/stderr.

### `GET /projects/{id}/documentation`
Returns markdown strings for `README.md`, system architecture overview, API documentation, setup instructions, and the final project report.
